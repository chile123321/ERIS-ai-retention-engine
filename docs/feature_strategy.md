# Feature strategy

V1 Full covers up to 25 approved IBM HR candidates. V2 Practical aligns inputs with the ERIS collection schema. The approved four-way v2 feature matrix and preferred 16-feature candidate are documented in `docs/feature_strategy_v2.md`. V3 Minimal reduces collection and standardization burden. Exact lists must come from approved sources and must not be guessed. Each release records both feature-set and schema versions.
