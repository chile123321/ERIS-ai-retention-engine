# Configs

Chỉ thêm config sau khi dataset mới đã được audit. Mỗi config phải được version hóa,
có report/trace tương ứng và mô tả provenance rõ ràng.

Không giữ config IBM trong active tree và không tạo placeholder giả cho target,
feature, vocabulary, preprocessing, model hoặc policy chưa được phê duyệt.
